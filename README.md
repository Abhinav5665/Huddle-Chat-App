# Huddle - Real-time Chat Application

Huddle is a real-time chat application that lets users create and join rooms to chat with each other instantly using WebSockets.

## Features
- Create and join chat rooms using a room code
- Real-time messaging via WebSockets
- Room based communication — messages only go to people in the same room
- Multiple users can connect to the same server and chat simultaneously
- Authentication (login / signup)
- Typing indicators — see when someone is typing
- Online presence — see who is currently in the room
- Message history — see previous messages when you join a room

## Tech Stack

**Frontend**
- React
- TypeScript
- Vite

**Backend**
- Node.js
- TypeScript
- WebSockets (ws library)
